The 7 rules that separate Cloudflare/Vercel from generic dashboards
4px corner radius. Vercel uses 4–6px, never 12+. Rounded = consumer app. Square-ish = infrastructure tool.
Dense information. 13px body text, tight leading. Dashboards aren't landing pages — no big whitespace heroes.
Mostly monochrome. Black, white, grays handle 90% of UI. Solar Yellow and Voltage Blue appear sparingly — not everywhere.
Borders, not shadows. Cloudflare/Vercel use 0.5–1px solid borders. Drop shadows = old enterprise UI.
Sentence case always. "Charge point settings", not "Charge Point Settings". See every Vercel label ever.
Fixed sidebar, scrollable content. Left nav with icon + label. Collapsible to icons on mobile. This is the pattern.
Status as semantic color. Green/amber/red for charger states — don't use brand colors for status. Reserve yellow for actions only.
Dark mode first. Cloudflare's dashboard is dark by default. Build tokens in CSS variables from day one — not bolted on later.

Data tablesUnknownTanStack Table + shadcn DataTable. Dense 36px rows.
ChartsUnknownRecharts with Kabisa color tokens. Voltage Blue as primary series.
Bottom line: You're building infrastructure software for EV operators — the aesthetic should feel like you belong next to Cloudflare and Vercel, not Shopify or Notion. shadcn/ui + Lucide + Geist + Tailwind is exactly the stack Cloudflare would have built on if they started today. Your Forward palette is strong — the problem is likely border radius too high, shadows where there should be borders, and icons that aren't on the same stroke grid as the rest of the UI.
